repairloop — build notes
========================

intent
------
mirror the write/run/grade loop from terminal-bench style science tasks,
but as a hackathon demo on Nebius + Nemotron instead of a closed eval harness.

v0 was a thin fence-stripper. that looked like a weekend toy.
v0.3 adds real tools, transcripts, oracles, more tasks, pytest, docker.

tasks
-----
easy:   thermistor_beta, wire_gauge_drop, quaternion_rotate, rc_step_response
medium: beamforming_delay, pid_step, snr_fft_tone, damped_modes

damped_modes is the stretch goal — DFT peak picking works on clean
separated tones; noisy K=3 can still flake on nano.

tavily
------
optional on purpose. when the key is present the model gets web_search
for formula reminders (beta model, array delay). graders never need net.

gotchas
-------
- some Nemotron deployments ignore tools → session falls back to fence parse
- always run `python -m repairloop.eval --oracles-only` before claiming a
  new task is fair
- don't commit .env or runs/
